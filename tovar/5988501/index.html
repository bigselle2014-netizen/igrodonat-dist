Описание от продавца

🎮 UC, игровые наборы, подписки и пропуски для PUBG Mobile по Player ID В одном товаре доступны разные виды товаров: 🔹 UC — игровая валюта PUBG Mobile для покупок во внутриигровом магазине. 🎁 Дополнительные наборы — First Purchase Pack, Weekly Deal Pack, наборы материалов и мифических эмблем. ⭐ Подписки — Prime и Prime Plus на разные периоды. 🏆 Пропуски — Elite Pass и Elite Pass Plus. Перед оформлением заказа обязательно проверьте во внутриигровом магазине, доступен ли выбранный товар для вашего аккаунта. ✅ Без передачи аккаунта ✅ Для получения товара необходим только Player ID ✅ Автоматическая доставка 24/7 📌 Как проходит автодоставка: 1️⃣ Выберите необходимое количество UC, набор, подписку или пропуск и укажите свой Player ID в специальном поле. 2️⃣ Оплатите заказ удобным способом. 3️⃣ После оплаты вы автоматически перейдёте на защищённую страницу доставки. 4️⃣ Система проверит покупку, получит Player ID и выбранный товар непосредственно из оплаченного заказа и автоматически отправит пополнение на выполнение. 5️⃣ Дождитесь успешного завершения заказа — статус доставки будет обновляться на странице автоматически. ❗ Внимательно проверяйте Player ID перед оплатой. ❗ Отправляйте только цифры Player ID, без никнейма и лишнего текста. Player ID для глобальной версии игры начинается с 5. ❗ Названия некоторых наборов и подписок могут отображаться в игре на английском языке. ❗ Пополнение недоступно для региональных версий игры, включая Китай, Тайвань, Корею, Японию и Вьетнам. ❗ Доступность отдельных наборов, подписок и пропусков зависит от аккаунта и текущих предложений во внутриигровом магазине. Перед покупкой обязательно убедитесь, что выбранный товар доступен для вашего аккаунта. Политика возвратов: • После отправки товара на указанный Player ID возврат средств не осуществляется. • Ошиблись в Player ID или случайно приобрели товар до его отправки — возврат с комиссией 20%. • Если выбранный набор, подписка или пропуск недоступен для вашего аккаунта — возврат средств не осуществляется. • В случае ошибки со стороны продавца — полный возврат средств. ⚡ Автоматическая доставка работает круглосуточно. Обычно выполнение заказа занимает несколько минут. Поддержка отвечает с 09:00 до 21:00 МСК.
